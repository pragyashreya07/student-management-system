# 🎓 Student Management System

A web-based Student Management System built using PHP and MySQL. The project provides secure login authentication and complete CRUD functionality for managing student records.

## ✨ Features

- 🔐 Admin Login & Logout
- 📊 Dashboard with Total Students
- ➕ Add Student
- 📋 View Students
- ✏️ Edit Student
- ❌ Delete Student
- 🔍 Search Students
- 🔤 Sort Students
- 💾 MySQL Database Integration

## 🛠 Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
- Git
- GitHub

## 📂 Project Structure

```
student-management-system/
│── index.php
│── login.php
│── logout.php
│── db_connect.php
│── add_student.php
│── view_students.php
│── edit_student.php
│── delete_student.php
│── style.css
│── student_management.sql
```

## 🚀 Installation

1. Install XAMPP.
2. Copy the project to the `htdocs` folder.
3. Import `student_management.sql` into phpMyAdmin.
4. Start Apache and MySQL.
5. Open:

```
http://localhost/student_management_system
```
